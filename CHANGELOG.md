## Version Naming Convention

- **MAJOR** version when you make incompatible API changes
- **MINOR** version when you add functionality in a backwards compatible manner
- **PATCH** version when you make backwards compatible bug fixes

---

## Changelog Guidelines

When contributing, please update the changelog with:
1. **Category** (Added, Changed, Fixed, Removed, Deprecated, Security)
2. **Description** of the change
3. **Issue number** (e.g., #123) if applicable
4. **Breaking changes** clearly marked

---

## How to Report Changes

To report a change or new feature:
1. Open an issue or PR
2. Reference the relevant issue number
3. Update CHANGELOG.md accordingly
4. Follow the format above
